## 数列が変わった

シードの読み方、ラベルの順番、タイムゾーン、消費回数を確認します。同じ関数は続き、新しい関数は最初からです。shuffle は渡した配列を変えます。乱数を 1 回増やしたり処理を変えたりすると、アルゴリズムが同じでも後の結果が変わります。互換性を変える前に仕様の検証値を確認します。

## 読み取りが null になる

`fromJSON` と `fromText`は不正、未対応、整合しない位置を拒否します。`dayOfSeed`は範囲外や実在しない日付の数字に null を返します。`parsePickerItems`は空、不正、上限を越える一覧に null です。要素の取得にはマウント前やシード未選択で null の場合があります。埋め込みガイドに説明があります。

## 例外になる

Pick と weightedPick には空でない項目が必要です。整数の境界と回数は関数の条件に合わせます。checkBlocks は不正な範囲や重なりを、drawSeed は全予約を拒否します。不正な日付、Date、タイムゾーンは RangeError になる場合があります。保存位置には整数のシードと負でない安全な回数が必要で、CSV は MAX_CSV_ROWS が上限です。

## React の値が古い

useSeeded はシードを見ており、取り込んだ任意の値には追従しません。他の依存を変える場合は key を変えます。フックはコンポーネント内で呼びます。useDailySeed は指定した場所を使い、サーバー描画とハイドレーションの間に日付が変わる場合があります。

## 秘密に使えるか

[既存の制限](../../../README.md#not-for-secrets)を確認してください。予測できることは再現するテストや問題のための機能で、暗号の予測困難さはありません。
