# Seeded picker and group embeds

The shared builder covers every attribute and explicitly explains host-only random streams, weights and callbacks. It writes all framework/HTML/frame formats with the installed package's major version. The setup URL includes the list and settings; it is intended for lists you want to share. Private host lists can be supplied through options.items instead.

Items is one nonempty item per line or a JSON string array. Lists are limited to 200 items, 200 characters per item and 20,000 characters overall. Input is inserted as text, never HTML. Seed uses the existing seedFrom behavior (numbers or hashed text); daily uses a validated UTC date and the native dailySeed. Today resolves on configuration or a draw, with no rollover timer. Mode is pick, shuffle or groups. Count selects up to the list length without replacement, using native sample; optional host weights use native weightedIndex without replacement. Shuffle uses native shuffled. Groups partition that shuffled order round-robin into balanced groups (at most 20 and at most the number of items).

The first draw appears when mounted. Pick advances the stream; reset reseeds and restores the first draw. Presentation and callback changes preserve the stream and result; input/seed/mode/count/weight changes restart it. GroupCount reflects group-count. All other attributes have direct reflected properties, with native lang. Result is a JSON-safe copy of { seed, mode, indices, groups }; selection maps the result to item text locally. Seed is null when a host-owned random stream is used. No raw item text is sent in native events or iframe messages.

Options accepts private items, seed, a native Random function (when no explicit seed/day is supplied), nonnegative per-item weights and onPick with the same index-only detail as the native event. A supplied random stream remains host-owned; reset cannot rewind it. DefinePicker(tagName?, registry?) is server-safe, idempotent and uses a subclass for custom names.

Size is small/medium/large (320/480/640px), with optional pixel width. Theme follows the device or is light/dark; label supplies a spoken group name. Original width and role/label are restored when removed. The native button is keyboard-operable, remains focused across draws, and results are announced politely. Controls=false hides the button but host methods remain available. No animation, timer, cookie or storage is used.

Tane-pick and tane-load carry only the structured indices/seed/mode/groups. Tane-error carries a plain message and shows a status. All events bubble and compose. Frame receivers should check the sender's origin and frame before accepting { type, detail }. The route validates lists, enums, bounded integers, seeds, booleans and real UTC dates and ignores malformed fields. It has noindex, transparent margins, device colour-scheme and no document scrolling. Builder heights allow longer later choices, and phone-width wrapping. It loads local modules; copied imports use jsDelivr.
